# Case: Uber ATG automated test vehicle (Tempe, Arizona, 2018)

Source: NTSB Highway Accident Report HAR-19/03. This is a description of the system and its use before the crash. It does not include the investigation findings.

## System
A modified Volvo XC90 SUV is used by Uber Advanced Technologies Group (ATG) to test an automated driving system (ADS) on public roads. The ADS is designed to drive the vehicle without human input in defined conditions, up to about 45 mph in this test program.

## Main parts
- Sensors: roof-mounted lidar, radar units and cameras covering the area around the vehicle.
- Perception: detects objects around the vehicle, classifies each one (for example vehicle, pedestrian, bicycle, other), and tracks it over time.
- Prediction: estimates where each tracked object will go next, using its class and recent movement.
- Planning and control: chooses a path and speed, and controls steering, throttle and braking.
- Vehicle: the Volvo factory driver-assistance features (such as forward collision warning and automatic emergency braking) are part of the base vehicle.

## People
- One vehicle operator sits in the driver seat. The operator is responsible for watching the road and taking over control when needed. The operator also uses a tablet-style interface to tag events and check system status.
- Other road users share the road: pedestrians, cyclists and other drivers. They are not aware of the test program.

## Operating context
Public multi-lane roads in an urban area, day and night, with posted speed limits, marked crosswalks, intersections and street lighting that varies by location.
